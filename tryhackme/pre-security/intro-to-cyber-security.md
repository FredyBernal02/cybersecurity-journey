# Introduction to Cyber Security

## Objective
Understand the basics of cybersecurity and the different areas within the field.

## Key Concepts
- Offensive Security
- Defensive Security
- Security Roles
- Importance of Cybersecurity

## What I Learned
Cybersecurity is divided into two main areas: offensive and defensive.

Offensive security focuses on attacking systems to find vulnerabilities, while defensive security focuses on protecting systems and preventing attacks.

There are different career paths in cybersecurity, including penetration tester, security analyst, and SOC analyst.

## My Understanding
Cybersecurity is not just hacking. It is about understanding systems, identifying risks, and protecting information.
