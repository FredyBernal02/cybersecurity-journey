# Defensive Security Introduction

## Objective
Understand the role of defensive security and how organizations protect systems from attacks.

## Key Concepts
- Blue Team
- Monitoring
- Incident Response
- Security Analysis

## What I Learned
Defensive security focuses on protecting systems, detecting attacks, and responding to security incidents.

Security teams monitor networks, analyze suspicious activity, and take action to prevent or minimize damage.

## My Understanding
Defensive security is about staying alert, identifying threats early, and protecting systems before they are compromised.
