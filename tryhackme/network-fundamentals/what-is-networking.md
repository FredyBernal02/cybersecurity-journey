# What is Networking?

## Objective
Understand what networking is, how the internet works, and how devices are identified in a network.

## Key Concepts
- Network
- Internet
- IP Address
- MAC Address
- ICMP / Ping

## What I Learned
Networking refers to devices that are connected to each other to share data and resources. A group of connected devices is called a network.

The internet is a massive network made up of smaller networks. It originated from ARPANET in the 1960s and later evolved with the creation of the World Wide Web by Tim Berners-Lee.

Devices in a network are identified using two main addresses:
- IP Address: A temporary address used to identify a device on a network.
- MAC Address: A permanent physical address assigned to a device by the manufacturer.

IP addresses can be:
- Public: Used to identify devices on the internet.
- Private: Used within local networks.

Internet Service Providers (ISPs) assign public IP addresses to users.

The current version of IP addressing is IPv6, which supports a very large number of unique addresses.

Ping uses the ICMP protocol to test communication between devices and check if a connection is working.

## My Understanding
Networking is the foundation of communication between devices. Every device needs an identity (IP and MAC) to send and receive data.

## Notes
Ping helps verify if a device is reachable on a network.
