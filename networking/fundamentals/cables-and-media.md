# Cables and Network Media

## Objective
Understand common network cable types, connectors, and transmission media.

## Key Concepts
- UTP
- RJ-45
- Straight-through cable 
- Crossover cable
- Auto MDI-X
- Fiber Optic
- SFP Transceiver
- EMI

## What I Learned 
UTP (Unshielded Twisted Pair) is a common copper cable used in Ethernet networks.

RJ-45 is the standard connector used with Ethernet cables.

Two common cable types are:
- Straight-through cable
- Crossover cable

Modern devices often support Auto MDI-X, which automatically detects transmit and receive pairs.

Fiber optic cables transmit data using light and offer:
- Longer distances
- Higher speed
- Better resistence to EMI 
- Better security (no signal leakage)

SFP transceivers are modular interfaces commonly use for fiber connections.

## UTP vs Fiber Optic

### UTP
- Lower cost
- Shorter distance (~100m typical)
- Vulnerable to EMI
- Common in homes/offices

### Fiber Optic
- Higher cost
- Longer distance
- Resistant to EMI
- Higher security

## My Undertanding
Different network media are chosen based on cost, speed, distance, and security needs.
