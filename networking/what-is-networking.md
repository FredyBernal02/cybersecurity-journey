# What is Networking?

## Objective
Understand what a computer network is, its components, and how devices communicate within a network.

## Key Concepts
- Network
- Nodes
- Client / Server
- LAN (Local Area Network)
- Switch
- Router
- Firewall

## What I Learned
A computer network is a digital communication system that allows devices (nodes) to share resources.

Examples of nodes include routers, switches, firewalls, servers, and clients.

A client is a device that requests services, while a server provides those services.

A LAN (Local Area Network) connects devices within a limited area, such as a home or office.

Switches are used to connect devices within the same network (LAN).

Routers connect different networks and allow communication between them, including access to the internet.

Firewalls monitor and control incoming and outgoing network traffic based on security rules.

## My Understanding
Networking allows devices to communicate and share information efficiently. Each device has a role, and together they form a system that enables communication within and between networks.

## Notes
- Switch = connects devices inside a network  
- Router = connects networks together  
- Firewall = protects the network
